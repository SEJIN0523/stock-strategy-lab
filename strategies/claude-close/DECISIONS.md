# 종가 스코어링 v1 구현 결정

[원본](original.md)은 보존합니다. [v1.json](v1.json)은 원본의 복제 완료본이 아니라 모호한 규칙을 해소한 별도 연구 후보입니다. 수익률을 본 뒤 결정한 최적값이 아닙니다. 원본의 40/40/20 점수와 두 단계 유동성·시가총액·재무 필터는 유지합니다.

| 쟁점 | 첫 연구 버전의 결정 |
| --- | --- |
| 최초 전액 매수와 3회 매수 충돌 | 최초 목표 금액의 1/3, 최초 체결 후 5·10거래일에 나머지 각 1/3 검토. 반드시 매수하는 일정이 아님 |
| 비중 복구 매수의 무제한 반복 | 독립 복구 분기를 끔. 모든 추가 매수는 같은 포지션의 총 3회 한도·잔여 목표금액 안에서만 허용 |
| 추가 매수 간격 | 체결된 거래 기준으로 거래 세션 인덱스를 사용. 추가 체결 사이에도 최소 5거래일 |
| 종목별 목표금액 | 최초 신호 시점 순자산/목표 종목 수로 정하고 전량 청산까지 고정. 현금을 모두 쓰도록 강제하지 않음 |
| 추천 15개와 보유 종목 수 | 15개는 후보 목록. 실제 동시 보유 상한은 기본 10개, 동일 업종 신규 진입은 기존 보유까지 합쳐 최대 3개 |
| 20~40% 탐색 매수 | 자동 운용에서는 제외. 별도 수동 안내로만 남김 |
| 40~70% 절반 매도 | `40 < 상위백분율 <= 70`, 평가금액이 목표의 60% 초과, 2주 이상일 때 수량의 절반(내림). 구간 진입 후 체결 기준 1회. 상위 40% 복귀 시 래치 해제 |
| 하위 30% | 상위백분율 `>70`이면 전량 매도. 정확히 70은 절반 매도 구간 |
| 당일 급락 | 신호일 확정 종가의 수익률 `<=-8%`이면 신규·추가 매수 보류. 다음 날 확정 종가로 사후 취소 여부를 정하지 않음 |
| 손절 시나리오 자료 미비 | 첫 기준 전략은 -15% 고정 연구값을 최초 체결 때 고정. 최적 손절률이라는 의미가 아님. 원본의 분포 기반 손절은 별도 후속 후보 |
| 손절가 하락 방지 | `max(이전 손절가, max(평균 매수가, 최고 종가)*(1+고정 손절률))`. 추가 매수 후에도 손절률을 느슨하게 바꾸지 않음 |
| 안내 함수와 관리 함수 | 실제 연구 판단은 manage 한 곳. decide 화면은 그 결과를 설명. 별도 -20% 손절·사용자 목표가 절반 매도를 자동 엔진에 섞지 않음 |
| 순위가 없어짐 | 일시 자료 누락은 신규·추가 매수 중단, 확인 가능한 기존 손절은 유지. 검증된 필터 탈락은 별도 전량 청산 사유. 결측 순위를 임의로 하위 30%로 취급하지 않음 |

## 시계열과 점수

- 신호 T는 KRX 정규 종가와 T까지 공개된 재무자료만 사용합니다. 정정 공시는 공개된 시점 이후에만 반영합니다.
- 52주 위치는 T까지 252거래일의 보정 고가·저가에서 계산합니다. 고가=저가이면 위치 0.5. 12개월 모멘텀은 `C[T-21]/C[T-252]-1`이며 최소 253개 유효 종가가 필요합니다.
- 백분위는 오름차순 순위, 동점은 평균 순위, 1개 표본은 50점입니다. 최종 상위백분율은 종합점수 백분위의 `100-백분위`입니다.
- 로그 시가총액 순위는 양수 시가총액 순위와 같으므로 같은 순위를 직접 사용합니다.
- EPS 성장률은 TTM EPS의 전년동기 대비 변화/전년동기 EPS 절댓값으로 정의합니다. 분모 0은 산출 불가로 표시합니다. EPS 양수 추천 필터는 별도로 유지합니다.
- 주식 수 감소율은 분할·병합의 기계적 수량 변화를 제거한 값이어야 합니다. 배당은 확정된 현금 배당의 비교 가능한 12개월 주당액을 사용하고, 전기 0의 증가율은 산출 불가로 둡니다.
- 선택 항목의 성장률만 없을 때 해당 성장 항목 점수 50을 사용합니다. 필수 EPS·BPS·재무 공개시점 자체가 없으면 평가 모집단에 들어가지 않습니다.
- 로그 변화율 절댓값 0.35 초과 배제는 원본의 위험 필터로 유지합니다. 데이터 오류 판정과 구분하며, 예컨대 -30% 하락이 이 필터에 걸린다는 사실을 숨기지 않습니다.

## 체결과 상태 갱신

종가 신호를 다음 거래 세션의 KRX 정규 종가 주문 의도로 예약합니다. 현재의 과거 단순 전략 엔진은 다음 날 **시가** 체결이므로 이 전략에 그대로 사용하지 않습니다.

수량은 T 종가로 미리 정하며 주문 예산을 예약합니다. T+1 확정 종가를 미리 보고 수량을 다시 계산하지 않습니다. 예약 예산·실제 주문 가능 현금을 초과하거나 정지·체결 불가이면 체결로 기록하지 않습니다. 같은 동시호가에서 매도될 것으로 기대하는 자금을 신규 주문 재원에 더하지 않습니다. 종가 체결 가정은 실제 체결을 보장하지 않습니다.

매수 횟수·첫 매수일·마지막 거래일·부분 매도 래치의 설정은 **신호가 아니라 체결 확인 시** 갱신합니다. 래치 해제는 확인된 상위 40% 복귀로 처리합니다. 미체결 주문은 한 실행 세션 뒤 취소하고 새 신호를 기다립니다. 손절·전량 매도 신호가 발생하면 대기 매수 의도를 취소해야 합니다. 현재 체결 확인 모듈은 연구용 전량 체결 이벤트만 지원하며 실제 부분 체결·주문 취소 확인은 아직 연결하지 않았습니다.

가격 보정은 신호용 보정 OHLC와 실제 체결용 원시 가격을 구분해야 합니다. 분할·병합 시 보유수량·평균단가·최고가·손절가를 같은 기준으로 조정하고, 현금 배당을 가격 보정과 중복 반영하지 않습니다. 이 처리가 완성되기 전에는 전체 수익률을 공표하지 않습니다.

## 연구 순서

1. 공시시점별 재무자료·가격 보정/기업행사·과거 업종 분류의 출처와 적재를 완성합니다.
2. 같은 모집단·매매 규칙에서 규모만 / 추세만 / 규모+추세 / 전체 40·40·20을 비교합니다. 신호 요소와 자금 관리 변경을 한 실험에서 동시에 바꾸지 않습니다.
3. 첫 기준은 고정 -15% 손절. 분포 기반 손절을 추가할 때는 결과 관측이 완전히 끝난 사례만 학습하고, 예측 기간이 평가 구간과 겹치는 학습 사례를 제외합니다. 표본 수·구간 안정성을 보고합니다.
4. 이미 열어 본 2026년 검증 구간은 탐색용으로 표시합니다. 순차 과거 구간 평가와 향후 모의 운용을 사용하며 재사용한 구간을 새로운 독립 검증이라고 부르지 않습니다.
5. 수수료·체결가격 차이 0, 과거 체결일별 매도 거래세를 유지합니다. 전략 성과와 체결 가능성은 별도로 검증합니다.
