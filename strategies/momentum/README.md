# 모멘텀 A v1 연구

기존 Claude 운영 코드와 독립된 첫 연구 후보다. [plan.json](plan.json)을 첫 실행 전에 고정했다. 수익성 인증·추천 채택·최적화 결과가 아니다.

## 첫 후보

- M1: 6개월 상승률 백분위와 최근 1개월을 뺀 12개월 상승률 백분위의 평균.
- M2: 동일한 모집단에서 M1 점수 80% + 60거래일 변동성이 낮을수록 높은 백분위 20%.
- M3 재무 수익성 결합은 공시시점별 재무자료 검증 후 별도로 구현한다. 없는 재무를 중립값으로 대체해 완성된 전략이라고 부르지 않는다.

진입 모집단은 유효 253개 시장 세션, 주가 1천원·20일 평균 실제 거래대금 10억원·시총 1천억원 이상, MA120 위, 두 모멘텀 양수다. 원시가격의 과거 ±35% 초과 단절은 미보정 위험으로 배제한다. 미래 사건이 생길 종목을 과거에서 제거하지 않는다. 시총은 선별 조건이고 점수 가중치는 없다. 원천의 보통주 분류는 이름·소속부 기반이며 역사 증권종류 마스터 완전 검증이 아니다.

각 평가구간 첫날을 기준으로 5거래일마다 순위를 갱신한다. 상위10에서 빈 자리에 진입하고 보유 종목은 상위20까지 유지한다. 매일 종가 기준 15% 트레일링 스톱과 MA60 하향 이탈을 점검한다. 순위 갱신일에는 자격 탈락·20위 밖도 매도한다. 우선순위는 손절→MA60→순위다. 최고종가 기반 손절선은 내려가지 않는다.

최대10종목·신규 목표10%·정수주·추가매수 없음. 보유 비중을 강제로 맞추지 않으며 순위/가격 변화로 실제 비중은 달라질 수 있다. 업종 상한과 시장 상황별 목표 현금비중은 아직 없다. 모든 수치는 최적값이 아닌 연구 시작값이며 사용자 손실 허용치로 간주하지 않는다.

## 실행과 기록

```text
node --test strategies/momentum/engine.test.js
node backend/momentum-research.mjs
```

선택적 첫 인자는 읽기 전용 원본 프로젝트 루트다. 원본 수집·수정·연구 스크립트 실행 없이 검증한 시세 파일만 읽는다. 현재 DB와 공유 코드/날짜의 OHLC·거래량·거래대금·시총·주식수·시장 값을 대조하고 충돌이 있으면 전략 실행을 중단한다. DB를 병합하거나 새 API를 호출하지 않는다.

계획·코드·가격 manifest 해시, 세부 주문·현금 장부와 요약은 Git 제외 `private-data/momentum-A-v1/`에 기록한다. 각 계좌는 같은 초기1억원에서 별도 시작한다. 개발2024년과 회고검증2025~2026년은 이미 사용한 자료로 미사용 검증이 아니다. 첫 두 후보 사이의 승자 선정은 하지 않는다. UI는 변경하지 않았다.

## 체결·데이터 한계

- A 방식: T 종가 신호→다음 거래일 종가 체결 대용. 수량/예산은 T에 정한다. 다음 종가로 수량을 새로 산정하지 않는다. 주문 전체가 예약 예산을 넘으면 취소한다.
- 예정 매도대금으로 신규매수를 예약하지 않는다. 신규 진입 때 전량매도 예정 자리를 미리 빈 자리로 세지 않는다.
- 일 거래량1%는 연구용 체결 상한이다. 마감 동시호가 물량·호가·상하한가 대기열을 검증한 체결 보장이 아니다. 매수 부분 체결의 잔량은 취소하고 매도 잔량은 이월한다.
- 수수료0·슬리피지0·체결일별 매도세만 적용한다. 현금 이자와 배당 현금은 미반영한 가격수익 시나리오다. 최종 보유는 평가하며 강제 청산세를 더하지 않는다.
- 보유 가격/상폐 정산 결측 또는 0.1% 초과 주식수 변동으로 기존 보유자 권리를 알 수 없으면 계좌를 중단하고 전기간 지표는 null로 둔다. 주식수 변동을 자동 분할로 해석하지 않는다. 대기 매수의 주식수 변동은 취소한다.
- 중단일이 다르면 공통 관측 종료일까지의 부분 결과만 나란히 표시한다. 1년 미만 구간은 CAGR을 산출하지 않는다.
- B 방식의 당일 마감 전 시각 자료가 없어 이번 실행은 A 내부 후보 비교뿐이다. A가 B보다 유리하다는 결론을 내리지 않는다.

## 첫 실행 확인

2,740개 가격 파일·2,886,309행을 해시 검증했고, 현재 DB와 겹치는1,244,568행의 비교 필드에서 충돌0건이었다. 이는 원천 정확성·전체 시장 완전성의 인증이 아니다.

첫 네 계좌는 모두 미해결 보유 주식수 변동에서 중단됐다. 개발 M1은2024-01-16, 개발 M2는2024-02-19의091440, 회고검증 M1은2025-03-25의226950, M2는2025-02-04의001530이다. 각 사건의 전후 주식수/가격·원천 해시·원문 후보는 `event-review-queue.json`에 남긴다. 알려진 연간 원문 저장소에는 해당 연도 원문3개가 없음을 확인했으며 다른 공시·출처의 존재 여부까지 부정하지 않는다. 사건을 삭제하거나 보유수량을 임의 조정해 전기간 수익률을 만들지 않았다.

다음 단계는 원문에 따른 기존 보유자 권리/현금 처리를 검증하고, 그 장부를 연결한 뒤 같은 고정 계획으로 최초 현금부터 재실행하는 것이다.
